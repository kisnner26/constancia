motor de animación · v1.0.0

fanal

animaciones largas en una sola toma, escritas como datos. canvas 2d y webgl2, sin build, sin dependencias. corre en el navegador y se instala como app de escritorio en macos y windows.

01

módulos

  • timelinesecuenciador de tomas, easing y keyframes
  • cameradolly, paneo, push-in, parallax y profundidad de campo
  • transitionsfundidos, iris, match cuts y cruces de luz
  • particlesluciérnagas, polillas, polvo y redes de neuronas
  • strokesdibujos a trazos con aguada y morph entre ellos
  • rigpersonajes por partes con respiración, parpadeo y pelo con física
  • gl · shaderspases webgl2 registrables: agujero negro lensado, julia, cielo, océano
  • audiografo webaudio por capas con compresor, reverb y automatización
  • playerune todo y reproduce una escena

02

una escena son datos

// scenes/mi-escena.js
import { fireflies } from '../engine/particles.js';

export default {
  name: 'mi-escena',
  shots: [{
    id: 'luces', dur: 10,
    camera: [{ t: 0, z: 1 }, { t: 10, z: 1.3 }],
    draw(S, env) {
      env.ctx.fillStyle = '#0a0705';
      env.ctx.fillRect(0, 0, S.w, S.h);
      fireflies(env.ctx, S.view, S.ta, { n: 20 });
    },
  }],
};

se abre con teaser.html?escena=mi-escena. hay una escena mínima funcionando en ejemplo.html y la api completa en engine/README.md.
